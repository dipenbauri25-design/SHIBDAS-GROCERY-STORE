# Shibdas Grocery Store — Android App Source

Branding configured for **Shibdas Grocery Store**.

## Included
- Customer Android UI
- Branded home screen using the supplied shop logo
- Grocery categories and search
- Product catalogue
- Cart and quantity controls
- Shop pickup checkout flow
- UPI/Cash payment UI foundation
- Order history/status screen
- Admin dashboard demo
- Product/order management foundation

## Store configuration
- Pickup location: Kashipur, Rangiladi
- Payment UPI is configured as a private app setting placeholder; keep it out of public source/repositories and replace it through secure production configuration.

## Production integrations still required
- Firebase Authentication
- Firestore database
- Firebase Cloud Messaging
- Secure admin authorization
- Verified UPI/payment gateway integration
- Real product images, inventory and prices

## Build
Open this project in Android Studio, sync Gradle, and run the `app` module.
This environment does not include the Android SDK/Gradle build toolchain, so an APK has not been falsely represented as compiled here.
